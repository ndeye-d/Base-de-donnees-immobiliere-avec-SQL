# 📊Base de données immobilière avec SQL
## 🎯Objectif
LaplaceImmo est un réseau d’agences immobilière qui a pour but d’analyser le marché et d’aider les agences régionales à accompagner leurs clients.

## 🛠️Outils
- **Power Query** : Consolidation des données
- **DuckDB** : Base de données
- **SQL** : Interrogation de la base de données
## 🚀Résultats
Les logements sont plus vendus et plus chers en **Ile-de-France** et les logements **2 pièces** sont les plus vendus
